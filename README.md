## 🎯 Objetivo del repositorio

Centralizar las actividades académicas realizadas por el Grupo 8 durante la cursada, facilitando la colaboración entre los integrantes, el seguimiento de los avances y la documentación de las soluciones desarrolladas.

Este repositorio permitirá:

- Organizar los proyectos y trabajos prácticos de la materia.
- Registrar las configuraciones, procedimientos y pruebas realizadas.
- Documentar las soluciones implementadas y sus resultados.
- Mantener un historial de cambios mediante Git.
- Facilitar la revisión y evaluación de las entregas.
- Promover el trabajo colaborativo y las buenas prácticas de documentación técnica.
